# UNES

**Site institucional estático de uma universidade fictícia desenvolvido como exercício de HTML5.**

---

## 📖 Sobre

O **UNES** é um projeto de estudo desenvolvido durante o curso **Domine Web - 20 Cursos**, disponível na Udemy. O projeto simula o site institucional de uma universidade fictícia e serve para praticar a estruturação de páginas com HTML5.

O projeto contém três páginas estáticas. A navegação é feita por links HTML, e os elementos visuais são carregados a partir de imagens locais armazenadas na pasta `imagens/`. Todo o conteúdo apresentado é fictício.

---

## ✨ Funcionalidades

- [x] Página inicial com apresentação da universidade
- [x] Página institucional com informações, motivos para estudar e objetivos
- [x] Página de contato com formulário demonstrativo
- [x] Navegação entre as páginas por links HTML
- [x] Recursos visuais carregados localmente

## 🚀 Começando

### Pré-requisitos

Não há pré-requisitos de instalação ou dependências externas.

### Executando

Como o projeto utiliza arquivos HTML estáticos, basta abrir o arquivo `index.html` em qualquer navegador moderno.

Também é possível abrir a pasta do projeto no Visual Studio Code e utilizar a extensão Live Server para visualizar as páginas com recarregamento automático.

---

## 💻 Uso

Use a barra de navegação das páginas para acessar:

- `index.html`: página inicial
- `quem_somos.html`: informações institucionais
- `contato.html`: formulário de contato

O formulário da página de contato é apenas demonstrativo. Ele não possui integração com um backend e não envia mensagens.
